Chhaya Advertising website

Open index.html in any browser. Every menu item is its own page (agency.html, clients.html, portfolio.html, careers.html, contact.html ...).
Keep the folders css/, js/ and images/ next to the .html files.
To upload: copy the whole folder to your web host.
